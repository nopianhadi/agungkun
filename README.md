# Jalankan dan terapkan aplikasi AI Studio Anda

Ini berisi semua yang Anda butuhkan untuk menjalankan aplikasi secara lokal.

Lihat aplikasi Anda di AI Studio: https://ai.studio/apps/c2c82724-97d4-40f0-bd07-05981f02dc17

## Jalankan Secara Lokal

**Prasyarat:** Node.js


1. Instal dependensi:
   `npm install`
2. Atur `GEMINI_API_KEY` di [.env.local](.env.local) dengan kunci API Gemini Anda
3. Jalankan aplikasi:
   `npm run dev`
